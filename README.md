# 📘 Foundation SQL Scripts

This repository contains a collection of foundational SQL scripts designed to support database setup, learning, and structured progression through essential SQL concepts. Each file builds on the previous one, creating a step-by-step approach to constructing tables, relationships, queries, and data operations.

## 📂 Contents

### **1️⃣ Foundation_1.sql**  
*Initial database setup*
- Creates the base database structure  
- Defines initial tables  
- Introduces primary keys and simple constraints  
- Sets up the foundation for subsequent scripts  

### **2️⃣ Foundation_2.sql**  
*Extending the schema*
- Adds new tables and relationships  
- Introduces foreign keys and referential integrity  
- Expands the database model with more realistic structures  
- Begins demonstrating intermediate SQL operations  

### **3️⃣ Foundation_3.sql**  
*Data manipulation & operations*
- Inserts sample data into previously defined tables  
- Demonstrates `SELECT`, `UPDATE`, `DELETE`, and filtering logic  
- Covers joins (INNER, LEFT, RIGHT) and practical query examples  
- Introduces aggregate functions and grouping  

### **4️⃣ Foundation_4.sql**  
*Advanced or final enhancements*
- Adds more advanced SQL components  
- May include views, stored procedures, functions, or triggers  
- Performs complex queries based on the built database  
- Provides a complete dataset environment for learning or testing  

## 💡 Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo.git
   
2. Run each SQL file in order (1 → 4) using your preferred SQL environment:
- MySQL Workbench
- SQL Server Management Studio (SSMS)
- PostgreSQL client
- Any SQL-compatible tool

**Note** : Ensure scripts are executed sequentially to avoid missing dependencies.

## 🎯 Purpose
This collection is ideal for:
- Students learning SQL and relational database design
- Developers setting up a starter database
- Interview preparation and SQL practice
- Anyone wanting clean, incremental SQL examples
